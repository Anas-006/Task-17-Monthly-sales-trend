Task 17 – Monthly Sales Trend

Objective

Summarize sales by month and visualize the trend using Python.

Tools

- Python
- Pandas
- Matplotlib

Approach

The dataset was prepared with Order Date and Sales fields. Order Date was converted into a datetime format. Sales were grouped by month and summed to create the monthly sales summary. A line chart was then created to visualize the sales trend.

Outputs

- "monthly_sales_table.csv"
- "monthly_sales_trend.png"

Result

The monthly table provides total sales for each month, and the line chart shows the movement of sales over time.
